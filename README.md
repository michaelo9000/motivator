# Meinforcer

[meinforcer.netlify.app](https://meinforcer.netlify.app/)

Add and edit one-off or regular tasks you want to motivate yourself to complete.

Add and edit personal rewards and their costs, and an amount of personal money you want to set aside to purchase rewards for yourself.

Check in when you have completed a task, and the number of times and dates on which it was completed are recorded.

Calculates how much each task is worth based on self-set goals, and rewards an according number of tokens to be spent on rewards.

Stores purchased rewards until they are redeemed.
